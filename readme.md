# Front-end Immersion

This project was developed during the Front-end Immersion, focused on practicing fundamental web development concepts, including HTML5, CSS3, and modern JavaScript.

## What was developed
- Responsive interface inspired by streaming platforms.
- Semantic component structuring.
- Advanced styling with CSS (Flexbox and Grid).
- DOM manipulation and API consumption for dynamic search.

## Technologies Used
- **HTML5**: Content structure.
- **CSS3**: Layout, variables, and responsive design.
- **JavaScript**: Search logic and user interaction.
- **JSON Server**: API simulation for artist and playlist data.

## How to run
1. Install dependencies (if any):
   ```bash
   npm install
   ```
2. Start the simulated API server:
   ```bash
   npm run server
   ```
3. Open the `index.html` file in your browser or use the Live Server extension.
